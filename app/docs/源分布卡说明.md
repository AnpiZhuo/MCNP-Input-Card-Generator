## 一、MCNP 四种源模式总览

| # | 源类型 | 触发卡片 | 适用场景 |
|---|--------|---------|---------|
| 1 | **通用源**（General Source） | `SDEF` | 日常固定源：点源、面源、体源、自定义能谱 |
| 2 | **面源**（Surface Source） | `SSW`（写）+ `SSR`（读） | 两步计算：先把粒子存文件，再读出来当源（如轫致辐射接力） |
| 3 | **临界源**（Criticality Source） | `KCODE` + `KSRC`/`HSRC` | Keff 临界计算（裂变链式自持） |
| 4 | **用户自定义源** | `SOURCE` 子程序 | SDEF/SSR/KCODE 都没有时默认调用，自己写 Fortran |

**源必须定义以下粒子变量**：ERG（能量）、TME（时间）、UUU/VVV/WWW（方向）、XXX/YYY/ZZZ（位置）、IPT（粒子类型）、WGT（权重）、ICL（起始栅元）、JSU（起始曲面）。

## 二、通用源 SDEF — 写法详解（3-54）

### 基本格式

```
SDEF 源变量 = 规格 ...
```

**空卡默认**：14 MeV 各向同性点源，位置 (0,0,0)，时间 0，权重 1。

三种赋值方式：
| 方式 | 示例 | 含义 |
|------|------|------|
| 直接给值 | `SDEF ERG=14 POS=0 0 0` | 固定值 |
| 分布编号 | `SDEF ERG=D1` | 从分布1取样，需配 SI/SP 卡 |
| 依赖分布 | `SDEF ERG=FERG D1` | 分布1依赖ERG变量，需配 DS 卡 |

### 源变量表（Table 3.3）

| 变量 | 含义 | 默认 |
|------|------|------|
| CEL | 起始栅元 | 由位置自动确定 |
| SUR | 起始曲面（0=体积源） | 0 |
| ERG | 能量（MeV） | 14 |
| TME | 时间（shakes） | 0 |
| DIR | 方向余弦（相对VEC） | 体积源：各向同性；曲面源：余弦分布 |
| VEC | 方向参考矢量 | 体积源：无；曲面源：法线 |
| NRM | 曲面法线符号 | +1 |
| POS | 位置参考点 | (0,0,0) |
| RAD | 径向距离 | 0 |
| EXT | 沿AXS距离 / 与AXS夹角余弦 | 0 |
| AXS | EXT/RAD参考轴 | 无 |
| X, Y, Z | 笛卡尔坐标 | 未定义 |
| CCC | Cookie-cutter 栅元 | 无 |
| ARA | 平面源面积 | 无 |
| WGT | 粒子权重 | 1 |
| EFF | 取样效率阈值 | 0.01 |
| PAR | 粒子类型 1=N,2=P,3=E,4=F(正电子) | 由MODE卡 |
| TR | 源变换 | 无 |

### 各类源的具体写法

**点源**：
```
SDEF POS=2 3 4 ERG=14 PAR=2
```
（X Y Z 三个坐标都指定 → 点源）

**多个点源**：
```
SDEF POS=D1
SI1 L 0 0 0 10 0 0 20 0 0     ← 三个位置
SP1 0.25 0.5 0.25              ← 概率
```

**球体源**（POS+RAD）：
```
SDEF POS=0 0 0 RAD=D1
SI1 5 10            ← 内外半径，默认幂律 a=2 → 体积均匀
```
（RAD=0 → 点源）

**柱体源**（POS+AXS+RAD+EXT）：
```
SDEF POS=0 0 0 AXS=0 0 1 RAD=D1 EXT=D2
SI1 0 2          ← 内外半径，默认 a=1 → 体积均匀
SI2 -5 5         ← 沿轴范围
```

**笛卡尔体积源**（X+Y+Z）：
```
SDEF X=D1 Y=D2 Z=D3
SI1 -2 2
SI2 -2 2
SI3 -2 2
```

**栅元体积均匀源**（CEL）：
```
SDEF CEL=2       ← 栅元2内体积均匀
```

**曲面源**（SUR）：
```
SDEF SUR=1 POS=0 0 0 RAD=D1   ← 平面源，POS必须在面上
SDEF SUR=5 AXS=0 0 1 EXT=D2   ← 球面源（AXS+EXT组合暗示球面）
```

**指定能谱**：
```
SDEF ERG=D1
SP1 -3            ← Watt 裂变谱（a=0.965, b=2.29）
SP1 -2            ← Maxwell 裂变谱
SP1 -4            ← 高斯聚变谱
```

**指定方向**：
```
SDEF DIR=1 VEC=0 1 0       ← 沿Y轴单方向
SDEF DIR=D1 VEC=0 1 0      ← 方向分布
SP1 -31 1.5                ← 指数偏倚
```

## 三、源分布卡 — SIn / SPn / SBn / DSn / SCn（3-63 ~ 3-67）

> 本节逐条改写自 MCNP6 手册 C810 第 3-63 ~ 3-67 页（`Source Specification` 卡的 SIn/SPn/SBn/DSn/SCn 段 + Table 3.4）。
> 下文凡标「原文」处均为手册原话的直译。

### SIn — 源信息卡

```
SIn option I1 ... Ik          （Form：option = Ii 的解释方式）
SIn H I1 ... Ik               （H / 省略 = 直方图分箱边界，仅标量变量；默认）
SIn L I1 ... Ik               （L = 离散源变量值）
SIn A I1 ... Ik               （A = 概率密度定义点）
SIn S I1 ... Ik               （S = 分布号）
```

| 项 | 含义 |
|----|------|
| `n` | 分布号（n = 1 ~ 999） |
| `option` | `Ii` 如何解释：省略或 `H` = 直方图的分箱边界（bin boundaries for a histogram distribution），**仅标量变量**，且**这是默认值**；`L` = 离散源变量值（discrete source variable values）；`A` = 概率密度定义点（points where a probability density distribution is defined）；`S` = 分布号（distribution numbers） |
| `I1 ... Ik` | 源变量值或分布号（source variable values or distribution numbers） |

Default：`SIn H I1 ... Ik`（省略 option 即 H）。
> 来源：C810 3-63 页原文。

> ⚠️ H 的默认性 ≠ L：无字母的 `SI2 -5.5 5.5` 是**直方图分箱边界**（箱内均匀／按 SP 给出的分箱概率），
> 不会自动补成 L。程序导入/生成保留原文语义（v2 双态：无字母 SI 记 type=""）。

### SPn — 源概率卡

```
SPn option P1 ... Pk          （第一种形态：常规表）
SPn f a b                     （第二种形态：f 为负数的内置函数）
SPn D P1 ... Pk               （D / 省略 = 分箱概率；默认）
SPn C P1 ... Pk               （C = 累积分箱概率）
SPn V P1 ... Pk               （V = 概率与栅元体积成比例，仅 CEL）
SPn f a b                     （f = 内置函数编号，a b = 内置函数参数，见 Table 3.4）
```

| 项 | 含义 |
|----|------|
| `option` | `Pi` 如何解释：**省略 = 若 SI 是 H 或 L 分布则同 `D`；若 SI 是 `A` 分布则为概率密度值**；`D` = H/L 分布的分箱概率（默认）；`C` = H/L 分布的累积分箱概率；`V` = **仅用于 CEL 源变量**，概率与栅元体积成比例（若给了 `Pi` 则再乘 `Pi`） |
| `Pi` | 源变量概率（source variable probabilities） |
| `f` | 内置函数编号（**负数**，designator for a built-in function） |
| `a b` | 内置函数的参数（见 Table 3.4） |

Default：`SPn D P1 ... Pk`。概率**不需要归一化**（need not be normalized）。
> 来源：C810 3-63 页原文。

> 判定规则：SP 的**第一种形态**——首项为**正数或非数值**——表示「这张 SP 与它的 SI 一起定义了一个概率分布函数」；
> 首项为**负数**则是第二种形态，即内置解析函数。

### H / A / L / S / V 五种 option 的抽样语义

**H — 直方图（SI 上的数值是分箱边界）**
- SI 上的数值是分箱边界（bin boundaries），必须**单调递增**（monotonically increasing）。
- SP 的**第一个数值项必须为 0**，其后各项是分箱概率（`D`）或累积分箱概率（`C`）。
- 抽样 = 先按分箱概率选一个箱，再**在该箱内均匀**取点（sampling uniformly within the chosen bin）。
> 来源：C810 3-63 页原文。

**A — 概率密度（SI 上的数值是概率密度定义点）**
- SI 上是**概率密度被定义处**的源变量值，必须**单调递增**；最低值与最高值界定变量范围。
- SP 上是对应的**概率密度值**，**不需要归一化**。
- 抽样时概率密度在**给定点之间线性插值**（linear interpolation）。
- SP 的**首项与末项通常为 0，但也允许非 0**。
> 来源：C810 3-63 ~ 3-64 页原文。

**L — 离散值**
- SI 上是源变量的**离散值**，例如栅元号、光子谱线能量。
- SP 上是这些离散值的概率（`D`）或累积概率（`C`）。
- SI 上的项**不需要单调递增**。
> 来源：C810 3-64 页原文。

**S — 分布号**
- 在若干分布间先选一个，再继续抽样；这样就不必把分布折到一起，
  且当**部分分布是离散的、部分是线性插值的，必须用 S**。
- SI S 上列出的分布**自身也可以再带 S 选项**；MCNP 支持约 **20 层**嵌套。
- SI 上每个分布号**可以带 `D` 前缀，也可以省略 `D`**；**分布号为 0 表示该变量用默认值**。
- 同一个分布可以出现在多处，但**一个分布不能用于一个以上的源变量**。
> 来源：C810 3-64 页原文。

**V — 按栅元体积加权（写在 SP 卡上）**
- 仅当源变量是 `CEL` 时使用；当栅元体积是发射概率的一个因子时很有用。
- 若 MCNP **无法算出该栅元体积、且卡上也没给 `VOL`**，是 **FATAL 错误**。
> 来源：C810 3-64 页原文。

### SBn — 源偏倚卡

```
SBn option B1 ... Bk          （与 SPn 同形；option = 空白 / D / C）
SBn f a b                     （f 只允许 −21 和 −31）
SBn D B1 ... Bk               （默认）
```

- `n`、`option`、`f`、`a`、`b` 与 `SPn` 相同，**但 `f` 只允许 −21 和 −31**。
- 用途：给出一个与实际概率分布（SP）**不同的**、用于抽样的概率分布，以改善收敛速度；
  **每个源粒子的权重都会被自动调整以补偿偏倚**。
- **所有适用于 SP 第一种形态的规则同样适用于 SB。**
> 来源：C810 3-63 ~ 3-64 页原文。

### SP / SB 上的内置函数（Table 3.4）

- **第二种形态**（首项为负）表示用**内置解析函数**为该源变量生成**连续**概率密度函数；内置函数**只能用于标量变量**。
- 内置函数**只能用于 Table 3.3 里列出的那些变量**：ERG / DIR / RAD / EXT / TME / X / Y / Z。
- **任何内置函数都可以用在 SP 卡上，但 SB 卡只允许 −21 和 −31。**
- 若某函数用在 SB 卡上，则对应的 SP 卡**只能**是**同一个函数**。
- **SI/SP 上的常规表 + SB 卡上的函数，这种组合不允许。**
- SP 卡上的内置函数可以（被 SI/SB 上的表）**偏倚**、或**截断**、或两者同时。
  偏倚**只影响各分箱的概率，不改变函数在各箱内的形状**；若被偏倚，函数在每个箱内被近似为 n 个等概率组，
  n 与箱数的乘积**尽可能大但不超过 300**。
- 除 −21 与 −31 外，因 SI 上的项**截断**了函数时，源粒子权重会被调整以补偿截断。
> 来源：C810 3-65 ~ 3-66 页原文。

**特殊默认**（C810 3-66 页原文 5 条）
1. 若存在 `SB f` 而没有 `SP f`，MCNP 会**等效提供一个用默认参数**的 `SP f`。
2. 若 RAD 或 EXT **只有 SI 卡**，会**等效提供**一个默认参数的内置函数 `SP −21`。
3. 若 DIR 或 EXT **只有 `SP −21` 或 `SP −31`**，会**等效提供** `SI 0 1`（对 −21）或 `SI −1 1`（对 −31）。
4. 若 RAD 上同时有 `SI x` 与 `SP −21`，该 SI **按 `SI 0 x` 处理**。
5. 若 EXT 上同时有 `SI x` 与 `SP −21` 或 `SP −31`，该 SI **按 `SI −x x` 处理**。

**Table 3.4 内置函数一览**

| 函数号 | 变量 | 名称 | 公式与默认值 |
|--------|------|------|--------------|
| `−2` | ERG | Maxwell 裂变谱 | p(E)=C·E^(1/2)·exp(−E/a)，a 为**温度**（MeV）；默认 a=1.2895 MeV |
| `−3` | ERG | Watt 裂变谱 | p(E)=C·exp(−E/a)·sinh(bE)^(1/2)；默认 a=0.965 MeV、b=2.29 MeV⁻¹；另见附录 H 第 H–3 页给出的各材料/自发裂变参数 |
| `−4` | ERG | 高斯聚变谱 | p(E)=C·exp[−((E−b)/a)²]，a 是宽度（MeV）、b 是平均能量（MeV）；宽度的定义是「b 之上使指数值等于 e⁻¹ 的 ΔE」；**若 a<0 则按温度解释（MeV），此时 b 也必须为负**；**b=−1 用 D–T 聚变能、b=−2 用 D–D 聚变能**（此时由程序算出并使用）；**a 不是半高宽（FWHM）**，二者关系 **FWHM = a·(ln 2)^(1/2)**；默认 a=−0.01 MeV、b=−1（D–T 聚变，10 keV） |
| `−5` | ERG | 蒸发谱 | p(E)=C·E·exp(−E/a)；默认 a=1.2895 MeV |
| `−6` | ERG | Muir 速度高斯聚变谱 | p(E)=C·exp{−[((E^(1/2) − b^(1/2))/a)²]}，a 是宽度（MeV^(1/2)）、b 是**对应平均速度的能量**（MeV）；宽度定义为「平均速度 b^(1/2) 之上使指数值等于 e⁻¹ 的速度变化」；a<0 时按温度解释（MeV）；b=−1 用 D–T、b=−2 用 D–D；默认 a=−0.01 MeV、b=−1（D–T 聚变，10 keV）；与 −4 近似可比时取 a = (b + a₄)^(1/2) − b^(1/2)，a₄ 为 −4 的宽度 |
| `−7` | ERG | 备用谱（Spare） | 框架已就位，便于用户自行加一条能谱（需改 SPROB / SPEC / SMPSRC，可能还有 CALCPS） |
| `−21` | DIR/RAD/EXT | 幂律 | p(x)=c·\|x\|^a；**默认 a 随变量变**：DIR 为 1；RAD 为 2，**但若定义了 AXS 或 JSU>0（即 JSU≠0）则为 1**；EXT 为 0 |
| `−31` | DIR/EXT | 指数 | p(μ)=c·e^(aμ)；默认 a=0 |
| `−41` | TME/X/Y/Z | 高斯 | p(t)=c·exp[−(1.6651092·(t−b)/a)²]，a 是**半高宽**、b 是均值；时间用 shakes、位置坐标用 cm；也可写成 p(t)=c·exp[−(t−b)²/(2σ²)]，因此半高宽 a=(8·ln 2)^(1/2)·σ |
> 来源：C810 3-65 ~ 3-66 页 Table 3.4 及原文。

### DSn — 依赖源分布卡

```
DSn option J1 ... Jk          （第一种形态）
DSn T I1 J1 ... Ik Jk         （自变量值后跟因变量值）
DSn Q V1 S1 ... Vk Sk         （自变量值后跟分布号）
DSn H J1 ... Jk               （默认）
```

| 项 | 含义 |
|----|------|
| `n` | 分布号（n = 1 ~ 999） |
| `option` | `Ji` 如何解释：空白或 `H` = 连续分布中的源变量值（**仅标量变量**）；`L` = 离散源变量值；`S` = 分布号；`T` = 因变量值跟在自变量值后面（自变量必须是**离散标量**变量）；`Q` = 分布号跟在自变量值后面（自变量必须是**标量**变量） |
| `Ii` | 自变量值 |
| `Ji` | 因变量值 |
| `Vi` | **单调递增**的自变量值集合 |
| `Si` | 因变量的分布号 |

Default：`DSn H J1 ... Jk`。
> 来源：C810 3-66 页原文。

**用途**：DS 卡**代替 SI 卡**，用来描述「依赖另一个源变量的变量」（在 SDEF 卡上以 `ERG=FPOS D2` 这类形式指定）；
**不使用 SP 或 SB 卡**。MCNP 先照常抽出自变量的值，再按 DS 卡确定因变量的值。

**H（空白或 H）**
- 若自变量的 SI 是 n 个箱的直方图（n+1 项），则 DS 卡必须有 n+1 项来描述 n 个箱；**第一项不必为 0**。
- 若抽到的自变量值为 `Ii + f(Ii+1 − Ii)`，则因变量值为 `Ji + f(Ji+1 − Ji)`（f 只在连续分布时用；
  **无论自变量分布是离散还是连续，插值因子 f 始终存在**）。

**L / S**
- n 个离散值需要 n 项。
- 自变量与因变量的分布**不必同为离散或同为连续**，所有组合都正常工作。

**T**
- 抽到的自变量值在 `Ii` 中查找，命中则因变量取对应的 `Ji`；**未命中则因变量取它的默认值**。
- 用途：当因变量「通常应取默认值」时可大幅缩短输入。

**Q**
- `Vi` 定义自变量的分箱；抽到的值**从 V1 开始比较**，一旦 `≤ Vi` 就抽样 `Si` 作为因变量值。
- **`Vk` 必须 ≥ 自变量任何可能取值**；**`Si` 为 0 表示该变量用默认值**。
- **Q 是自变量分布为内置函数时唯一可用的 DS 形态。**

> 来源：C810 3-66 ~ 3-67 页原文。

### SCn — 源注释卡

```
SCn comment                   （n = 分布号 1 ~ 999）
```

- 该注释会作为分布 n 的**表头**打印在**源分布表**与**源分布频率表**里。
- **`&` 续行符号被视为注释的一部分，而不是续行命令。**
- Default：无注释。Use：推荐用于复杂源描述。
> 来源：C810 3-67 页原文。

> 解析器支持（2026-08-16）：SCn 属于分布家族，SDEF 后收集链不再被 SCn 打断；
> 注释文字结构化进分布条目 `sc` 字段，生成器回放 `SCn 注释文字`（inp02.i 实卡验证）。

## 四、面源 SSW / SSR — 写法详解（3-70）

### 第一步：SSW 写面源文件

```
SSW S1 S2 (C1 ... Ck) S3 keyword=values
```

| 参数 | 含义 |
|------|------|
| Si | 记录粒子穿过的曲面编号（宏体曲面不允许） |
| Ci | 栅元编号：正=进入该栅元，负=离开该栅元 |
| SYM | 0=无对称（默认）；1=球对称（只能一个球面）；2=双向记录 |
| PTY | N/P/E 记录粒子类型，缺省=全部 |
| CEL | 临界计算中记录裂变源的栅元 |

**示例**：
```
SSW 4 -7 19 (45 -46) 16 -83 (49)
```
曲面19记录：进入45或离开46的粒子；曲面83记录：进入49的；曲面4/7/16：全部。

### 第二步：SSR 读面源文件

```
SSR keyword=values ...
```

| 关键字 | 含义 |
|--------|------|
| OLD S1 S2... | 读原文件中的哪些曲面 |
| CEL C1 C2... | 读原文件中的哪些裂变栅元 |
| NEW S11 S12... | 新问题中粒子从哪些曲面出发（面→面映射） |
| PTY | 读哪些粒子类型 |
| COL | -1=仅无碰撞直接粒子；1=仅碰撞后粒子；0=全部 |
| WGT x | 每个粒子权重乘 x |
| TR n / TR Dn | 变换：把面源变换到新位置（多个位置用分布） |
| PSC c | 探测器/DXTRAN 用的角度分布幂次（0=各向同性） |

**球对称专用**（原 SSW 用 SYM=1）：AXS、EXT、POA、BCW。

**示例 1：变换面源到多个位置**
```
SSR OLD 3 2 NEW 6 7 12 13 TR D5 COL 1
SI5 L 4 5
SP5 .4 .6
SB5 .3 .7
```

**示例 2：球对称源偏倚**
```
SSR AXS 0 0 1 EXT D99
SI99 -1 .5 1
SP99 C .75 1
SB99 .5 .5
```

**示例 3：三束交汇**
```
SSR OLD 2 TR=D1 WGT 6.0
SI1 L 11 22 33
SP1 1 1 1
TR11 ...
TR22 ...
TR33 ...
```

### 面源注意事项
- 记录方向只有单向（除 SYM=2）
- **NPS 改变会重新分配权重**：NPS **变小**→按比例**拒绝**轨迹；NPS **变大**→轨迹**复制**且每条权重减半（例：100→200，每条复制成 2 条各半权重）
- 探测器/DXTRAN 需要 PSC 近似，靠近源时可能 WRONG
- 面源文件默认名 WSSA（异常终止时是 WXXA，需与 RUNTPE 一起保存）

## 五、临界源 KCODE — 写法详解（3-77）

### KCODE 卡

```
KCODE NSRCK RKK IKZ KCT MSRK KNRM MRKP KC8
```

| 参数 | 含义 | 默认 |
|------|------|------|
| NSRCK | 每周期源历史数 | 1000 |
| RKK | 初始 Keff 猜测 | 1.0 |
| IKZ | 跳过（不累计记数的）周期数 | 30 |
| KCT | 总周期数 | IKZ+100 |
| MSRK | 分配源点存储 | 4500 或 2×NSRCK |
| KNRM | 0=权重归一 / 1=历史数归一 | 0 |
| MRKP | MCTAL/RUNTPE 保存周期数 | 6500 |
| KC8 | 0=全部周期 / 1=仅活跃周期 | 1 |

### KSRC — 初始源点

```
KSRC x1 y1 z1 x2 y2 z2 ...
```
- 每个可裂变区域至少一个点
- 点必须远离栅元边界
- 至少一个点必须在含裂变材料的栅元中
- 初始能量从 Watt 谱取样（a=0.965, b=2.29）
- 缺省：用 SRCTP 文件或 SDEF 卡提供初始源

### HSRC — 香农熵网格

```
HSRC nx xmin xmax  ny ymin ymax  nz zmin zmax
```
- 评估裂变源收敛性的 3D 网格
- 每方向 5~10 个格点为宜
- 缺省：MCNP 自动确定（最少 4×4×4）

### 完整临界计算写法
```
MODE N
KCODE 10000 1.0 50 150
KSRC 0 0 0 5 5 5
```

## 六、用户自定义源 SOURCE 子程序（3-79）

当 SDEF/SSR/KCODE 都缺省时，MCNP 调用用户提供的 `SOURCE` 子程序。

```
SUBROUTINE SOURCE
    ...  用户代码设置源变量 ...
    XXX = ...   ! 位置
    YYY = ...
    ZZZ = ...
    ERG = ...   ! 能量
    WGT = ...   ! 权重
    IPT = ...   ! 粒子类型
RETURN
END
```

要点：
- 方向余弦 UUU/VVV/WWW 默认已设为各向同性，需要各向同性就不用管
- 随机数用 `RANG()` 生成 0~1
- 数据可用 IDUM/RDUM 卡传入（各最多50项）
- 探测器/DXTRAN + 各向异性源需要额外写 `SRCDX` 子程序
- 备用数组 `SPARE(M)`（M=1~3）可自由使用，MCNP 不重置

## 七、示例汇总

### 示例1：带能量分布的均匀点源
```
SDEF ERG=D1 POS=x y z WGT=w
SI1 H E1 E2 ... Ek
SP1 D 0 P2 ... Pk
SB1 D 0 B2 ... Bk
```
（H 分布时 SP/SB 的首个数值项必须为 0（占位项），其后才是分箱概率——写成 `D0` 会被读成一个 token。）

### 示例2：球面源 + 指数偏倚
```
SDEF SUR=m AXS=i j k EXT=D6
SB6 -31 1.5
```

### 示例3：向内发射的球面源
```
SDEF SUR=m NRM=-1 DIR=D1 WGT=w
SB1 -21 2
```

### 示例4：体积均匀源（Watt谱）
```
SDEF ERG=D1 POS=x y z CEL=m RAD=D2 AXS=i j k
SP1 -3
SI2 -3 3
```

### 示例5：单方向平面源 + cookie-cutter
```
SDEF SUR=m POS=x y z RAD=D1 DIR=1 CCC=n
SI1 r
```

### 示例6：两位置点源，各自不同能谱

SDEF POS=D1 ERG=FPOS D2

### 示例7：直线均匀源 + 变换
