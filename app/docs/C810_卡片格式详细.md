# MCNP 输入卡格式详细说明
> 源: D:\MCNP\MCNP6\C810.pdf  |  MCNP5 Vol.II Ch.3

## 1. 栅元卡 (CELL CARDS)

#### 基本格式
```text
  j  m  d  geom  params
```

```text
  j     = 栅元编号 (1 <= j <= 99999)
  m     = 材料编号 (m=0 表示真空)
  d     = 密度: +数=原子密度(10^24/cm^3), -数=质量密度(g/cm^3)
  geom  = 几何描述: 有符号曲面号, :(并), #(补), ()(优先级)
  params= keyword=value 参数 (IMP, VOL, U, FILL, TRCL, ...)
```

#### LIKE m BUT 格式
```text
  j  LIKE k BUT  keyword=val  ...
  继承栅元k的全部描述, 只修改指定的参数
```

#### 示例
```text
  1  0  -1  2  -3  4  -5  6                $ 立方体
  2  1  -2.7  -2                          $ 材料1, 密度2.7
  3  0  -1 : 2 : -3                       $ 并集
  4  0  #2                                $ 补集
  10  LIKE 1 BUT  MAT=3  RHO=-1.2          $ 同形状, 改材料
```

## 2. 曲面卡 (SURFACE CARDS)

#### 通用格式
```text
  j  type  params
```

平面:
```text
  P     A B C D         $ Ax+By+Cz=D
  PX    D               $ x=D
  PY    D               $ y=D
  PZ    D               $ z=D
```

球面:
```text
  SO    R               $ 球心原点, x^2+y^2+z^2=R^2
  SX    Xc R            $ 球心在x轴
  SY    Yc R
  SZ    Zc R
  S     Xc Yc Zc R      $ 一般球面
```

柱面:
```text
  CX    R               $ x轴向, y^2+z^2=R^2
  CY    R
  CZ    R
  C/X   Xc Yc Zc R      $ 一般柱面, 平行x轴
  C/Y   Xc Yc Zc R      $ 平行y轴
  C/Z   Xc Yc Zc R      $ 平行z轴
```

锥面:
```text
  KX    x0 t2 (±1)       $ y^2+z^2-t2*(x-x0)^2=0；省略 ±1 = 双叶锥
  KY    y0 t2 (±1)       $ x^2+z^2-t2*(y-y0)^2=0；+1 = 朝 +轴 那一叶（锥外为正侧）
  KZ    z0 t2 (±1)       $ x^2+y^2-t2*(z-z0)^2=0
  K/X   x0 y0 z0 t2 (±1) $ 轴平行 X（顶点为前三项）
  K/Y   x0 y0 z0 t2 (±1) $ 轴平行 Y
  K/Z   x0 y0 z0 t2 (±1) $ 轴平行 Z
```

二次曲面:
```text
  SQ    A B C D E F G x0 y0 z0  $ A(x-x0)^2+B(y-y0)^2+C(z-z0)^2+2D(x-x0)+2E(y-y0)+2F(z-z0)+G=0
                                $ （D/E/F 是带系数 2 的**线性项**，SQ 无 xy/yz/zx 交叉项）
  GQ    A B C D E F G H J K     $ Ax^2+By^2+Cz^2+Dxy+Eyz+Fzx+Gx+Hy+Jz+K=0
```

环面:
```text
  TZ    x0 y0 z0 A B C     $ (z-z0)^2/B^2 + ((r-A)^2/C^2) = 1, r=√((x-x0)^2+(y-y0)^2)
  TX    x0 y0 z0 A B C     $ A 主半径；B 管的轴向次半径；C 管的径向次半径
  TY    x0 y0 z0 A B C     $ 正侧 = 外侧
```

椭圆柱面（**C810 的 Table 3.1（3-13）没有椭圆柱面助记符**）:
```text
  # TXY / TXZ / TYZ 三种写法在 C810 全文不存在（旧版误列，已删）
  # 椭圆截面柱面请用 GQ 或 SQ；宏体里对应的是 REC（右椭圆柱）
```

轴对称曲面（由坐标点定义；C810 3-15 ~ 3-16）:
```text
  X     x1 r1 [x2 r2] [x3 r3]     $ 关于 x 轴对称，点为 (x, r) 对
  Y     y1 r1 [y2 r2] [y3 r3]     $ 关于 y 轴对称，r = sqrt(x^2 + z^2)
  Z     z1 r1 [z2 r2] [z3 r3]     $ 关于 z 轴对称
  点对数决定曲面: 1 对 -> 平面(PX/PY/PZ)
                  2 对 -> 线性曲面(CX/CY/CZ, KX/KY/KZ 等)
                  3 对 -> 二次曲面(SO/SX/SY/SZ, SQ 等)
  同一曲面的所有点必须落在同一叶，否则 FATAL
  例: j X 7 5 3 2 4 3      $ 过 (7,5)(3,2)(4,3)，双叶双曲面
  反例: j Y 1 2 1 3 3 4    $ 落在两个平行平面上 -> FATAL
  两点指定锥面时只生成单叶锥；SQ 的感度定义为远离对称轴一侧为正
```
```text
  # 注意: X/Y/Z 不是"坐标平面"。坐标平面用 PX/PY/PZ(单值) 或 P(四系数)。
```

Macrobody(宏体):
```text
  BOX   Vx Vy Vz  A1x A1y A1z  A2x A2y A2z  A3x A3y A3z
  RPP   Xmin Xmax Ymin Ymax Zmin Zmax
  SPH   Vx Vy Vz R
  RCC   Vx Vy Vz  Hx Hy Hz  R
  REC   Vx Vy Vz  Hx Hy Hz  V1x V1y V1z  V2x V2y V2z
  # REC可用缩略格式: REC Vx Vy Vz  Hx Hy Hz  V1x V1y V1z  rMinor
  TRC   Vx Vy Vz  Hx Hy Hz  R1 R2
  ELL   Vx Vy Vz  Ux Uy Uz  Wx Wy Wz  RM
  WED   Vx Vy Vz  A1 A2 A3  B1 B2 B3  C1 C2 C3
  ARB   (8点x,y,z) (6个4位面编号)
  RHP/HEX  v1 v2 v3  h1 h2 h3  r1 r2 r3  s1 s2 s3  t1 t2 t3
```

## 3. 源卡 (SOURCE CARDS)

### 3a. SDEF 通用源卡

#### 格式
```text
  SDEF  var=val  var=val  ...
  赋值方式: val=显式值, =Dn(从分布n采样), =Fvar Dn(依赖分布)
```

#### 源变量列表
```text
  CEL = 栅元号           (默认: 由XYZ确定)
  SUR = 面号(面源)       (默认: 0=体源)
  ERG = 能量(MeV)        (默认: 14)
  TME = 时间(shakes)     (默认: 0)
  DIR = 方向余弦         (体源各向同性, 面源p(mu)=2mu)
  VEC = 参考矢量(x y z)  (体源: 除非各向同性否则必给; 面源: 法向, 符号由NRM定)
  NRM = 法向符号(+1/-1)  (默认: +1)
  POS = 参考点(x y z)    (默认: 0 0 0)
  RAD = 径向距离         (默认: 0)
  EXT = 沿AXS距离/夹角余弦(默认: 0)
  AXS = 参考轴(x y z)    (默认: 无方向)
  X   = x坐标            (默认: 无)
  Y   = y坐标            (默认: 无)
  Z   = z坐标            (默认: 无)
  CCC = cookie-cutter栅元(默认: 无)
  ARA = 面面积           (默认: 无; 仅平面面源对点探测器的直穿贡献需要)
  WGT = 初始权重         (默认: 1)
  EFF = 位置抽样拒绝效率 (默认: 0.01)
  PAR = 粒子类型         1=N, 2=P, 3=E; 4 或 F = 正电子(MODE E / P E / N P E)
  TR  = 变换编号 TR=n 或 TR=Dn (默认: 无)
  (以上默认值逐项取自 C810 Table 3.3, 3-55 ~ 3-56)
```

#### 示例
```text
  SDEF  ERG=14.0  POS=0 0 0            $ 14MeV点源
  SDEF  ERG=D1  CEL=2  X=D2  Y=D3  Z=D4  $ 体源+拒绝
  SDEF  SUR=1  NRM=-1  ERG=14.0          $ 面向内的面源
  SDEF  PAR=2  ERG=0.511  POS=0 0 0      $ 0.511MeV光子点源
```

### 3b. SI/SP/SB/DS 分布卡

SIn (源信息卡) 格式:
```text
  SI[n] [type]  vals...
  类型: L=离散列表, A=等间距对数, H=等间距线性, S=子分布
```

SPn (源概率卡) 格式:
```text
  SP[n] [option]  P1 ... Pk        $ 常规表
  SP[n]  f  a  b                   $ f 为负的内置函数(见 Table 3.4)
  option: 省略 = H/L 分布时同 D; A 分布时为概率密度值
          D = H/L 分布的分箱概率(默认)
          C = H/L 分布的累积分箱概率
          V = 仅 CEL 变量: 概率正比于栅元体积(给了 Pi 则再乘 Pi)
  首项为正或非数值 -> 常规表; 首项为负 -> 内置解析函数
  H 分布时 SP 的第一个数值项必须为 0(占位); 概率不必归一化
```

SBn (源偏倚卡) 格式:
```text
  SB[n] [type]  vals...
```

DSn (依赖分布卡) 格式:
```text
  DS[n]  var  Dn1  Dn2  ...
```

#### 示例
```text
  SDEF  ERG=D1
  SI1  L  0.1  1.0  14.0     $ 三种能量离散
  SP1  D                       $ 等概率
```

```text
  SDEF  DIR=FERG D2            $ DIR依赖ERG
  DS2  ERG                     $ 依赖ERG
  SI2  H  0  1                 $ ERG=0.1时DIR均匀0~1
  SI3  H  -1  1                $ ERG=1.0时DIR均匀-1~1
```

### 3c. KCODE 临界源卡

#### 格式
```text
  KCODE  NSRCK  RKK  IKZ  KCT  MSRK  KNRM  MRKP  KC8
  NSRCK = 每代源历史数              (默认 1000; 常用 1000~10000)
  RKK   = 初始 keff 猜测            (默认 1.0)
  IKZ   = 跳过(不累计记数)的代数     (默认 30)
  KCT   = 总代数                    (默认 IKZ+100)
  MSRK  = 源点存储上限              (默认 4500 或 2*NSRCK 取大)
  KNRM  = 归一化 0=权重 / 1=历史数   (默认 0)
  MRKP  = MCTAL/RUNTPE 保存代数     (默认 6500)
  KC8   = 0=全部代数 / 1=仅活跃代数  (默认 1; 取 0 不建议使用)
  (以上 8 项默认值逐字取自 C810 3-77)
```

#### 示例
```text
  KCODE  10000  1.0  50  500
  KSRC   0  0  0  2  0  0  -2  0  0
```

## 4. 计数卡 (TALLY CARDS)

### 4a. Fn 基本计数定义卡

#### 通用格式
```text
  Fn:pl  S1  S2  ...  Sk
  n   = 编号 (1,2,4,5,6,7,8, 或+10)
  pl  = 粒子: N,P,E,N,P,P,E
  Si  = 曲面/栅元编号, T=所有条目并集
```

#### F1 面电流
```text
  F1:N/P/E  s1 s2 ...
  *F1:N/P/E  s1 s2 ...    $ MeV
```

#### F2 面平均通量
```text
  F2:N/P/E  s1 s2 ...
  *F2:N/P/E  s1 s2 ...    $ MeV/cm^2
```

#### F4 栅元平均通量
```text
  F4:N/P/E  c1 c2 ...
  *F4:N/P/E  c1 c2 ...    $ MeV/cm^2
```

#### F5 探测器
```text
  F5:N/P  x y z  R0           $ 点探测器
  F5a:N/P  a r  R0            $ 环探测器 (a=X/Y/Z)
  FIR5:N/P  X1 Y1 Z1 0 X2 Y2 Z2 F1 F2 F3  $ 平面放射成像
  FIC5:N/P  ...               $ 柱面放射成像
  FIP5:N/P  ...               $ 针孔成像
```

#### F6 能量沉积
```text
  F6:N/P/N,P  c1 c2 ...   $ MeV/g
  *F6:N/P  c1 c2 ...       $ jerks/g
```

#### F7 裂变能量沉积
```text
  F7:N  c1 c2 ...   $ MeV/g
```

#### F8 脉冲高度谱
```text
  F8:P/E/P,E  c1 c2 ...   $ 脉冲数
  *F8:P/E/P,E  c1 c2 ...   $ MeV (能量沉积)
  +F8:E  c1 c2 ...         $ 电荷 (电子电荷单位)
```

#### 示例
```text
  F4:N  1  2  3
  F4:P  (1 2) 3 4
  F5:P  0 0 100  1
  F8:P  1  2  3
  *F8:P  1  2  3             $ 能量沉积
```

## 5. 材料卡 (MATERIAL CARDS)

### 5a. Mn 材料定义卡

#### 格式
```text
  Mn  ZAID1  f1  ZAID2  f2  ...  [kw=val ...]
```

```text
  n    = 材料编号 (1~99999)
  ZAID = ZZZAAA.nnX
    ZZZ=原子序数(1~98), AAA=质量数(0=天然)
    nn=库标识(可选, 如60), X=类型字母(可选, 依据 C810 第 2 章 CROSS SECTIONS 节):
      c=连续能量中子表     d=离散反应表      m=多群中子表      g=多群光子表
      p=光原子表(元素级 ZZZ000.nnP)        e=电子表(元素级 ZZZ000.nnE)
      u=光核表             y=剂量表(dosimetry)
      (热散射 S(alpha,beta) 走 MTm 卡, 如 lwtr.10t；不在此字母表内)
  fi   = 份额: +数=原子分数, -数=质量分数
```

#### 关键字=值
```text
  GAS=n   : 0=固/液, 1=气态
  ESTEP=n : 电子子步增加数
  NLIB=id : 默认中子库
  PLIB=id : 默认光原子库
  PNLIB=id: 默认光核库
  ELIB=id : 默认电子库
  COND=n  : 传导态 (<0非导, 0默认, >0导)
```

#### 示例
```text
  M1  1001  2  8016  1            $ H2O, 原子分数
  M2  26000  -0.95  6000  -0.05   $ 钢, 质量分数95%Fe+5%C
  M3  92235.60c  0.05  92238.60c  0.95  $ 5%浓缩铀
  M4  1001  .6667  8016  .3333  GAS=1  $ 水蒸气
```

## 6. PHYS 物理卡

### 6a. PHYS:N (中子)

#### 格式
```text
  PHYS:N  EMAX  EMCNF  IUNR  DNB  FISNU
```

```text
  EMAX  = 中子能量上限(MeV), 默认=极大
  EMCNF = 俘获方式转变能(MeV), 默认=0.0
           高于此=隐含俘获(权重降低), 低于此=模拟俘获(死亡)
  IUNR  = 0=打开(默认), 1=关闭未分辨共振概率表
  DNB   = -1=自然(默认), 0=无缓发, >0=每裂变DNB个缓发
  FISNU = <0=用-FISNU高斯宽度, 0=整数采样(默认), 1=推荐高斯, 2=原始Terrell
```

#### 示例
```text
  PHYS:N  20.0  0.1  1  -1  1
```

### 6b. PHYS:P (光子)

#### 格式
```text
  PHYS:P  EMCPF  IDES  NOCOH  ISPN  NODOP
```

```text
  EMCPF = 详细/简单分界能量(MeV), 默认=100
           >EMCPF: 简单(光电+康普顿+电子对,无荧光)
           <EMCPF: 详细(含荧光+相干散射+电子束缚)
  IDES  = 0=产生次级电子(默认), 1=不产生
  NOCOH = 0=含相干散射(默认), 1=关闭
  ISPN  = 0=无光核(默认), -1=模拟采样, 1=偏倚采样
  NODOP = 0=含Doppler展宽(默认), 1=关闭
```

#### 示例
```text
  PHYS:P  100  0  0  1  0
```

### 6c. PHYS:E (电子)

#### 格式
```text
  PHYS:E  EMAX  IDES  IPHOT  IBAD  ISTRG  BNUM  XNUM  RNOK  ENUM  NUMB
```

```text
  EMAX  = 电子能量上限(MeV), 默认=100
  IDES  = 0=光子产生电子(默认), 1=不产生
  IPHOT = 0=电子产生轫致光子(默认), 1=不产生
  IBAD  = 0=完整角分布(默认), 1=简单角分布
  ISTRG = 0=采样能损(默认), 1=期望值能损
  BNUM  = 轫致光子倍增  (>0=倍, 0=不产生)
  XNUM  = X射线倍增    (>0=倍, 0=不产生)
  RNOK  = 撞出电子倍增  (>0=倍, 0=不产生)
  ENUM  = 光致电子倍增  (>0=倍, 0=不产生)
  NUMB  = 轫致辐射每子步控制  (>0=每子步产生, 0=常态默认/默认)
```

#### 示例
```text
  PHYS:E  100  0  0  0  0  1  1  1  1
```

## 7. 截断卡 (CUTOFF CARDS)

### 7a. CUT:n 截断卡

#### 格式
```text
  CUT:N/P/E  T  E  WC1  WC2  SWTM
```

```text
  T    = 时间截断(shakes, 1sh=1e-8s), >T时被杀
  E    = 低能截断(MeV), <E时被杀
  WC1  = 权重上限截断
  WC2  = 权重下限截断(低于此值触发轮盘赌)
  SWTM = 最小源权重(用于负值截断时归一)
```

#### 默认值
```text
  中子: T=极大  E=0.0  WC1=-0.50  WC2=-0.25  SWTM=自动
  光子: T=同中子  E=0.001  WC1=-0.50  WC2=-0.25
  电子: T=同中子  E=0.001  WC1=0  WC2=0
```

#### 权重截断规则
```text
  当 WGT < R*WC2 (R=源imp/当前imp):
    概率 WGT/(R*WC1) 存活, 新权重=R*WC1, 否则杀
  负值: 用 |WC1|*Ws, |WC2|*Ws (推荐)
```

#### 示例
```text
  CUT:N  1e8  1e-6  -0.5  -0.25
  CUT:P  3J  -0.10                 $ 用前3个默认, 改WC2
```

### 7b. 其他截断卡

ELPT:n (逐栅元能量截断):
```text
  ELPT:N/P/E  E1  E2  ...  EI
  实际使用 max(ELPT_i, CUT:n E)
```

NPS (历史数截断):
```text
  NPS  N  [NPSMG]
  N=总历史数, NPSMG=FIR直穿贡献数
  示例: NPS  1000000
```

CTME (计算机时间截断):
```text
  CTME  minutes
  示例: CTME  30
```

NOTRN:
```text
  NOTRN    $ 禁止散射输运, 只计算直穿
```

## 9. 输入文件结构

#### INP 文件块结构

```text
  [消息块]          可选, 空行终止
  标题行            第1行, 1-80列
  [栅元卡块]         空行终止
  [曲面卡块]         空行终止
  [数据卡块]         隐式终止(无空行要求)
```

#### 通用格式规则

```text
  (1) 每行不超过 80 列
  (2) 卡片名/编号必须在 1-5 列内开始
  (3) 条目之间用一个或多个空格分隔
  (4) 注释: 1-5 列内任意位置出现 'C' 且后跟至少一个空格 = 整行注释卡;
      '$' = 行内注释($ 起至行尾全部按注释处理)
  (5) 空行是各块的分隔符/终止符(栅元块、曲面块、数据卡块)
  (6) 续行: 前五列留空 = 续行(主规则); 行尾以空格后的 '&' 结尾亦可续行
  (7) nJ = 跳过 n 个参数(取默认值); n 省略时按 1 记
  (8) nR = 重复紧邻的前一个条目 n 次
  (9) nI = 在前后两条目之间插入 n 个线性插值
  (10) nILOG = 插入 n 个对数插值(前后两项须非零且同号, 否则 FATAL)
  (11) xM = 以"前一条目 * x"作为本条目(省略 x 是 FATAL)
  (12) 关键字=值, =号可省略
  (13) 粒子标识符: :N :P :E 跟在卡片名后
  (14) 未指定的参数取默认值; 要求整数的位置必须给整数
```
