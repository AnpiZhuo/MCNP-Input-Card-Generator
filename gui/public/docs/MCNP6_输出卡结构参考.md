# MCNP6 输出卡（Output Card）结构参考

> 来源：MCNP6 手册 C810.pdf，第 3-143 ~ 3-164 页
> 范围：Peripheral Cards 中控制输出的卡片

---

## 一、输出卡体系总表

| 助记符 | 卡片类型 | 页码 |
|--------|---------|------|
| `PRDMP` | 打印与转存周期控制 | 3-143 |
| `PRINT` | 输出打印表选择 | 3-149 |
| `TALNP` | 记数分箱打印控制 | 3-151 |
| `MPLOT` | 运行中记数绘图 | 3-151 |
| `PTRAC` | 粒子径迹输出 | 3-152 |
| `LOST` | 粒子丢失控制 | 3-145 |
| `DBCN` | 调试输出控制 | 3-146 |
| `RAND` | 随机数参数 | 3-145 |
| `FILES` | 输出文件创建 | 3-148 |

## 二、各卡片格式

### 2.1 PRDMP — 打印与转存周期（3-143）

```
PRDMP NDP NDM MCT NDMP DMMP
```

| 参数 | 说明 | 默认 |
|------|------|------|
| NDP | 打印间隔：> 0 = 每 NDP 个历史打印一次；< 0 = 每 \|NDP\| 分钟打印一次 | end（仅末尾） |
| NDM | 转存间隔：同 NDP 逻辑，单位历史或分钟 | -60（每60分钟） |
| MCT | ≠ 0 时在末尾生成 MCTAL 文件（ASCII 记数文件，可绘图） | 0 |
| NDMP | RUNTPE 文件中保留的最大转存数 | all |
| DMMP | 并行：rendezvous 点间隔；串行：TFC 条目间隔 | 0（见下表） |

**DMMP 取值含义**：

| DMMP | 串行模式 | 并行模式 |
|------|---------|---------|
| < 0 | TFC 每 1000 个粒子 | TFC + rendezvous 每 1000 粒子 |
| = 0 | TFC 每 1000 粒子（初始），后倍增 | 共 10 次 rendezvous（均匀分布） |
| > 0 | TFC 每 DMMP 个粒子 | TFC + rendezvous 每 DMMP 粒子 |

**默认行为**：计算成功结束后才打印。每 60 分钟转存一次。不写 MCTAL 文件。全部转存写入 RUNTPE。

**临界计算说明**：正数 NDP/NDM 视为**周期数**而非粒子数。

### 2.2 PRINT — 输出打印表（3-149）

```
PRINT x1 x2 ...
```

- 无参数（空白）→ 完整输出
- `x1 x2 ...` → 基础输出 + 指定表号的表格
- `-x1 -x2 ...` → 完整输出 - 排除指定表号的表格

**默认**（无 PRINT 卡）→ 缩减输出（short output）。

**基础输出**（始终打印，不可关闭）：
- 输入文件列表
- 粒子产生与丢失的问题摘要
- KCODE 周期摘要
- 记数（tallies）
- 记数涨落图（TFC）

**常用打印表编号**：

| 表号 | 类型 | 描述 |
|------|------|------|
| 10 | basic | 栅元重要性 |
| 20 | basic | 栅元温度 |
| 30 | basic | 截面表 |
| 40 | default | TFC 分箱记数分析 |
| 50 | | 源系数与分布 |
| 60 | | 曲面系数 |
| 70 | | 栅元体积与质量、曲面面积 |
| 80 | | 记数描述 |
| 85 | | 网格记数描述 |
| 86 | | 重合探测器 |
| 90 | | 材料组成 |
| 98 | basic | 强迫碰撞与指数变换 |
| 100 | default | f(x) 记数密度图 |
| 102 | default | 累积 f(x) 与记数密度图 |
| 110 | | 源系数与分布（可选） |
| 120 | | 曲面积分 |
| 126 | | 重要性函数质量分析 |
| 128 | | 宇宙映射（重复结构，需初始运行开启） |
| 130 | basic | 各栅元粒子活动 |
| 140 | | 中子/光子/电子权重平衡 |
| 150 | | 核素活动 |
| 160 | | DXTRAN 诊断 |
| 161 | | 权重窗生成器摘要 |
| 162 | | 权重窗生成窗口 |
| 170 | | 问题截断总结 |
| 175 | shorten | keff 按周期估计 |
| 178 | | keff 按批次大小估计 |
| 190 | | 物理常数与编译选项 |
| 198 | | ESPLT/TSPLT 重要性比率 |
| 200 | | 电子射程与 Straggling 表 |

**示例**：
```
PRINT 110 40 150     → 基础表 + 表 40/110/150，不输出默认表 160-162
PRINT -70 -110       → 全部输出，排除表 70 和 110
```

### 2.3 TALNP — 记数分箱打印控制（3-151）

```
TALNP [n1 n2 ...]
```

- 无参数 → **关闭所有**记数的分箱详细打印
- `n1 n2 ...` → 仅关闭指定编号记数的分箱打印

**继续运行恢复**：
- 在 continue-run 的 INP 文件中用 `TALNP -n1 -n2 ...` 恢复指定记数的分箱打印
- `TALNP 0` → 恢复所有记数的分箱打印

**用途**：减少 OUTP 文件大小，特别是大网格成像（FIR/FIC/FIP）时。

---

### 2.4 MPLOT — 运行中记数绘图（3-151）

```
MPLOT MCPLOT keyword=parameter ...
```

- 在计算过程中按间隔调用 MCPLOT 绘制中间记数结果
- 默认间隔：`FREQ 5000`
- 不可用命令：RMCTAL、RUNTPE、DUMP、END
- 也支持运行时 `<ctrl-c>` 交互式进入 MCPLOT

---

### 2.5 PTRAC — 粒子径迹输出（3-152）

```
PTRAC keyword=parameter(s) keyword=parameter(s) ...
```

- 默认文件名：PTRAC
- 无关键字 = 记录所有粒子事件（**注意**：文件可能极大）
- 三类关键字：**输出控制**、**事件过滤**、**历史过滤**

**输出控制关键字**：

| 关键字 | 参数 | 默认 | 说明 |
|--------|------|------|------|
| BUFFER | 整数 > 0 | 100 | 文件写入缓冲区大小 |
| FILE | asc / bin | bin | ASCII 或二进制格式 |
| MAX | 8 字节整数 | 10000 | 最大写入事件数 |
| MEPH | 整数 > 0 | — | 每个历史最大事件数 |
| WRITE | pos / all | pos | 仅正值或全部 |

**示例**：
```
PTRAC FILTER=8,9 erg EVENT=sur NPS=1,50 TYPE=e CELL=3,4
```
仅记录历史 1~50 中、能量 8~9 MeV 的电子穿出栅元 3 或 4 的曲面事件。

> PTRAC 卡在 continue-run 中非法。

---

### 2.6 LOST — 粒子丢失控制（3-145）

```
LOST LOST(1) LOST(2)
```

| 参数 | 说明 | 默认 |
|------|------|------|
| LOST(1) | 允许丢失的最大粒子数，超限则 BAD TROUBLE 终止 | 10 |
| LOST(2) | debug 打印的最大次数 | 10 |

> 不鼓励使用此卡。丢失超过 10 个粒子通常是几何错误。

---

### 2.7 DBCN — 调试输出控制（3-146）

```
DBCN X1 X2 X3 ... X20
```

常用控制：

| 位置 | 默认 | 说明 |
|------|------|------|
| X2 | — | 每 X2 个历史打印一次调试信息 |
| X3 X4 | — | 历史号范围：打印 X3~X4 的完整事件日志 |
| X5 | 600 | 每个历史事件日志的最多事件数 |
| X11 | — | = 1 时打印丢失粒子事件中的碰撞行 |
| X15 | 0 | ≠ 0 时打印所有记数分箱的偏移置信区间和 VOV |
| X16 | 1 | 记分网格范围乘子（表 161/162） |

---

### 2.8 RAND — 随机数参数（3-145）

```
RAND keyword=value ...
```

| 关键字 | 默认值 | 说明 |
|--------|-------|------|
| GEN | 1 | 随机数生成器类型：1=MCNP Lehmer 48-bit；2/3/4=L'Ecuyer 63-bit |
| SEED | 19073486328125 | 初始种子（末尾必须为奇数） |
| STRIDE | 152917 | 源粒子之间的随机数步长 |
| HIST | 1 | 将生成器推进到指定历史编号 |

> 用于重现问题结果。RAND 参数优先于 DBCN 中的对应位置。

---

### 2.9 FILES — 输出文件创建（3-148）

```
FILES unit_no filename access form record_length
```

- unit_no = 1~99
- access = sequential / direct
- form = formatted / unformatted
- 最多 6 个文件
- continue-run 中非法

**示例**：
```
FILES 21 ANDY S F 0 22 MIKE D U 512
```

## 三、输出文件类型

| 文件名 | 说明 | 生成条件 |
|--------|------|---------|
| OUTP | 标准输出文件（文本） | 始终生成 |
| RUNTPE | 运行转存文件（二进制，用于 continue/restart） | 始终生成 |
| MCTAL | 记数 ASCII 文件（用于 MCPLOT 绘图） | PRDMP MCT ≠ 0 |
| PTRAC | 粒子径迹文件 | PTRAC 卡 |

---

## 四、注意事项

1. **PRINT 卡**：执行行上的 PRINT 选项优先级高于 INP 文件中的 PRINT 卡。
2. **表 128**：重复结构宇宙映射表必须在**初始运行**中开启，continue-run 无法打开。
3. **表 175**：无法完全关闭，但可用 `PRINT -175` 缩短为每 100 周期 + 最后 5 周期。
4. **PTRAC**：极大文件风险，务必使用过滤关键字。
5. **TALNP**：仅控制分箱详细打印，不影响记数计算结果。
