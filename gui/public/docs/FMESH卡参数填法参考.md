## 1. 概述

**FMESHn（Fixed Mesh Tally，固定网格计数）** 是 MCNP 的网格计数卡：在一张固定的三维网格上记录粒子通量/流，结果写入 MESHTAL 文件，可供 3D 体积可视化。

- **卡头**：`FMESHn:N/P/E` —— `n` 为计数卡号；`:N/P/E` 为粒子设计符（N=中子、P=光子、E=电子）。
- **与 Fn 计数卡的关系**：FMESHn 的卡号 `n` 与普通 Fn 计数卡号**独立编号**（实现将 number 与 particle 独立存储，不与 F 卡号关联校验）——⚠️待 C810 原文回填（C810 3-118 原文的编号规则待人工核对，见 §8 清单 1）。
- **几何**：`GEOM=xyz`（直角系）为默认；项目另支持 `REC`（直角）、`CYL`/`RZT`（圆柱系）。⚠️`GEOM=sph`（球系）项目与 PyMCNP 均不支持，C810 有无 sph 待核对（§8 清单 2）。
- **卡体格式总览**（蒸馏骨架，来源：C810 3-118，页级核验待回填）：

```
FMESHn:N/P/E  GEOM=xyz  ORIGIN=x0 y0 z0
          IMESH=val  IINTS=val
          JMESH=val  JINTS=val
          KMESH=val  KINTS=val
```

- **续行格式**：生成器按 MCNP 标准续行规则输出——续行以 **5 空格缩进** 开头（第 1~5 列为空白即续行），每行一个 `关键字=值`。同一逻辑行内也可以像骨架那样一行放多个 `KEY=val`（MCNP 均接受；本生成器输出为每 key 一行）。

## 2. 必填字段速查表

> 说明：`IMESH/IINTS` 等以「边界 + 区间数」成对出现，算作一组。速查共 **7 组 10 个输入项**。

| # | 字段 | 填什么 | 默认/约束 | 版本来源 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | `number`（卡号 n） | 计数卡号，如 `4` | 未填时默认 `4`（模板行为） | 项目实现（fmeshState.ts:95）；C810 编号规则 ⚠️待回填 |
| 2 | `particle`（粒子） | `N` / `P` / `E` | 未填默认 `N` | 项目实现；C810 设计符集合 ⚠️待回填（H/A/S 合法性待核对） |
| 3 | `geom`（几何） | `XYZ` / `REC` / `CYL` / `RZT` | 未填默认 `XYZ`；CYL/RZT 为圆柱系 | 项目实现（FMESH_GEOM_OPTIONS）；C810 取值集合含不含 rec/cyl/rzt、有无 sph ⚠️待回填 |
| 4 | `origin`（原点） | 三个坐标值，如 `-100 -100 -150` | 必填；直角系下各向网格首值须 > 对应坐标 | C810 3-118 骨架有 ORIGIN；是否必填原文 ⚠️待回填 |
| 5 | `imesh` + `iints`（X 向） | 边界值 + 区间数（正整数） | 多值=多区间，条目一一对应；边界单调递增；首值 > ORIGIN x | C810 3-118；多区间是否 MCNP5 行为 ⚠️待回填 |
| 6 | `jmesh` + `jints`（Y 向） | 同 X 向 | 同上 | 同上 |
| 7 | `kmesh` + `kints`（Z 向） | 同 X 向；圆柱系 θ 向末值须为 1 | 同 X 向；直角系首值 > ORIGIN z | 同上；圆柱系规则 ⚠️待回填 |

**卡文本示例**（number=4、particle=N、geom=XYZ、ORIGIN=-100 -100 -150、单区间）：

```
FMESH4:N GEOM=XYZ ORIGIN=-100 -100 -150
     IMESH=100
     IINTS=1
     JMESH=100
     JINTS=1
     KMESH=50
     KINTS=1
```

## 3. 可选字段「留空即默认」表

> 以下字段均可留空。留空时的行为/默认值除注明外均为**项目实现行为**，⚠️待 C810 原文回填（详见 §8 清单 5~8）。

| 字段 | 作用 | 留空即默认 / 备注 | 版本来源 |
| :--- | :--- | :--- | :--- |
| `emesh` + `emints` | 能量分箱：边界 + 区间数 | 空 = 不分箱。关键字生成发 `EMINTS=`，导入容错 `EINTS`/`EMINTS`；值须单调递增、条目一一对应。⚠️能量单位（MeV？）待 C810 回填 | 项目实现；关键字 MCNP6（契约 §4.7.1）⚠️ |
| `tmesh` + `tmints` | 时间分箱：边界 + 区间数 | 空 = 不分箱。生成发 `TMINTS=`，导入容错 `TINTS`/`TMINTS`；值须单调递增。⚠️时间单位（shakes？）待 C810 回填 | 项目实现；关键字 MCNP6 ⚠️ |
| `mat` | 材料过滤：只统计指定材料号的栅元 | 默认语义「0 = 粒子所在格材料（默认），非 0 = 指定材料号」。⚠️MAT 是否 MCNP5 FMESHn 合法关键字及默认语义待 C810 回填 | 项目实现（fmeshState.ts:184）⚠️ |
| `out` | 输出格式/单位 | 默认 `COL`。九选项：`COL`（默认）/ `CF` / `COLSC` / `CFSC` / `IJ` / `IK` / `JK` / `NONE` / `XDMF`。⚠️OUT 默认值（COL？）、取值集合、XDMF 是否 MCNP6.2+ 专属待 C810 回填 | 项目实现（FMESH_OUT_OPTIONS）⚠️ |
| `axs` + `vec` | 圆柱系轴向量 / 方向向量（各 3 分量） | 圆柱系（CYL/RZT）使用；AXS 与 VEC 不可平行（校验规则 5）。⚠️C810 对圆柱系 AXS/VEC 的默认值/必填性待回填 | 项目实现 ⚠️ |
| `tr` | 变换编号（正整数） | 可选；对网格做坐标变换。⚠️C810 是否有 TR 待核对 | 项目实现 ⚠️ |
| `raw` | 原文卡体兜底 | 结构化字段为空时原样回放 raw（round-trip 保真），不由用户直接填写 | 项目实现（契约 §5.3） |

> **未收录关键字提醒**：`DOS` / `UNIT` / `PDATA` / `TRACK` / `COR` / `DIMS` / `FACTOR` 等在项目实现与 PyMCNP fmesh 选项族中**均不存在**，高度疑似 MCNP6 TMESH（RMESH/CMESH）专属关键字；C810（MCNP5 FMESHn）应标注「未收录/不支持」。⚠️待人工核对 C810 3-118 全文确认无这些词（§8 清单 7）。

## 4. 通用模板两档（与前端「一键填充」一致）

前端表单提供两档通用模板，一键填入网格字段（只覆盖 `origin/imesh/iints/jmesh/jints/kmesh/kints`；`geom/particle/number` 仅在未填时给默认 `XYZ / N / 4`；其余字段保持用户已填值不变）。模板数值为**项目内置示例网格**，非 C810 原文建议。

### 4.1 minimal —— 最小可用（1×1×1）

> 单网格快速验证卡能否跑通。卡文本（number=4、particle=N）：

```
FMESH4:N GEOM=XYZ ORIGIN=-100 -100 -150
     IMESH=100
     IINTS=1
     JMESH=100
     JINTS=1
     KMESH=50
     KINTS=1
```

网格规模 1×1×1 = 1 单元。

### 4.2 starter —— 通用起步（20×20×10）

> 推荐：先粗网格看分布，再按需加密。卡文本：

```
FMESH4:N GEOM=XYZ ORIGIN=-100 -100 -150
     IMESH=100
     IINTS=20
     JMESH=100
     JINTS=20
     KMESH=50
     KINTS=10
```

网格规模 20×20×10 = **4000 单元**，3D 渲染开销小。

| 模板 | 网格规模 | ORIGIN | IMESH/IINTS | JMESH/JINTS | KMESH/KINTS |
| :--- | :--- | :--- | :--- | :--- | :--- |
| minimal | 1×1×1 = 1 | -100 -100 -150 | 100 / 1 | 100 / 1 | 50 / 1 |
| starter | 20×20×10 = 4000 | -100 -100 -150 | 100 / 20 | 100 / 20 | 50 / 10 |

> 两档模板应用后均通过全部校验（§5），且网格规模 ≤ 128³（2,097,152）不触发内存警告。

## 5. 五条必守规则（校验规则 + 错误示例）

> 来源：`gui/src/volume/fmeshState.ts` `validateFmeshRow`。以下规则为**项目实现校验**（填卡友好提示），其中 3/4/5 与 MCNP 语义相关处 ⚠️待 C810 原文回填确认。

**规则 1：区间数（`*ints`）必须为正整数（每个 ≥ 1）。**
- 覆盖：`iints / jints / kints / emints / tmints`。
- 错误示例：`IINTS=0`、`IINTS=-1`、`IINTS=1.5` → 报错「IINTS 须为正整数（每个区间数 ≥ 1）」。

**规则 2：网格边界与区间数条目一一对应（多区间时）。**
- `IMESH=10 20 30` 必须配 `IINTS=n1 n2 n3`（3 条目）；条目数不等 → 报错「IINTS 条目数（n）与 IMESH（m）不匹配」。
- 一侧有值一侧空 → 报错「缺少对应的 X 网格边界/区间数」。
- 注意：`1INTS n` 简写语法 **v1 不支持**（解析器无 `1INTS` 键），须改写为多值形式；C810 是否收录 `1INTS` ⚠️待回填（§8 清单 4）。

**规则 3：网格/能量边界值须单调递增；直角系（XYZ/REC）下各向首值须大于 ORIGIN 对应坐标。**
- 单调递增：`IMESH=10 10 20`（相等）或 `IMESH=20 10`（递减）→ 报错「IMESH 值须单调递增」。
- 直角系从原点起：ORIGIN x=-100 时 `IMESH=0` 或 `IMESH=-50` → 报错「IMESH 首值 -50 须大于 ORIGIN X 坐标 -100（网格从原点起递增）」。⚠️原文是否要求「首值大于 ORIGIN」、多值边界是否只约束首值，待 C810 回填（§8 清单 3）。

**规则 4：圆柱系（CYL/RZT）下 `kmesh` 末值须为 1（θ 为转数，末值 1 = 整圈 360°）。**
- 错误示例：圆柱系 `KMESH=2 4` → 报错「圆柱系（CYL/RZT）下 KMESH 末值须为 1」。⚠️圆柱系 i/j/k 方向语义与角度单位是否在 C810 原文，待回填（§8 清单 8）。

**规则 5：圆柱系 `axs` 与 `vec` 不可平行；`tr` 须为正整数。**
- `AXS=0 0 1` 配 `VEC=0 0 2`（同向/反向）→ 报错「AXS 与 VEC 不能平行（圆柱轴与网格方向需不同）」。
- `TR=-3`、`TR=1.5` → 报错「TR 须为变换编号（正整数）」。

**附加提示（警告，非错误）：网格规模上限提醒。**
- 三方向区间总数乘积 > **128³ = 2,097,152** 时给出警告「网格规模 i×j×k = N 单元，超出 128³ 渲染预算，3D 体积渲染内存/性能开销大」。
- ⚠️注意：128³ 阈值是**本项目 3D 渲染预算**（fmeshState.ts:493-494，契约 §2/§12），**与 C810 无关**；C810 是否给出网格单元数/内存建议待核对（§8 清单 9），未确认前不得引用为 C810 内容。
