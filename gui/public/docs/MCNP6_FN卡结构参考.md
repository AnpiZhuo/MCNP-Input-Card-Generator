# MCNP6 记数卡（Tally Card）结构参考

> 来源：MCNP6 手册 C810.pdf，第 3-80 页起
> 整理日期：2026-07-22

---

## 一、概述

记数卡（Tally Card）用于指定蒙特卡罗计算中用户期望获取的信息类型：穿过曲面的电流、某点的通量、某个区域中的能量沉积等。

**只需 `Fn` 卡即可获得记数结果**，其余记数卡提供各种可选功能。

所有记数均归一化为**每个源粒子**（per source particle），除非用户在临界（KCODE）计算中通过 TALLYX 子程序或权重修改。

## 三、7 种基本记数类型（Fna 卡）

MCNP 提供 7 种标准记数，涵盖中子（:N）、光子（:P）和电子（:E）。

### 3.1 记数类型总表

| 助记符 | 描述 | 单位（无*） | 单位（有*） |
|--------|------|-----------|-----------|
| **F1:N / F1:P / F1:E** | 穿过曲面的**电流**（Surface Current） | particles | MeV |
| **F2:N / F2:P / F2:E** | 曲面上平均的**通量**（Surface Flux） | particles/cm² | MeV/cm² |
| **F4:N / F4:P / F4:E** | 栅元中平均的**通量**（Cell Flux） | particles/cm² | MeV/cm² |
| **F5:N / F5:P** | 点或环**探测器**通量（Point/Ring Detector） | particles/cm² | MeV/cm² |
| **F6:N / F6:N,P / F6:P** | 栅元中**能量沉积**（Energy Deposition） | MeV/g | jerks/g |
| **F7:N** | 栅元中**裂变能量沉积**（Fission Energy Deposition） | MeV/g | jerks/g |
| **F8:P / F8:E / F8:P,E** | **脉冲高度**（Pulse Height）/ 能量沉积 / 电荷沉积 | pulses | MeV / charge |

### 3.2 记数类型细分说明

#### F1 — 曲面电流
- 统计穿过曲面的粒子数（或能量）
- `*F1` = 能量 × 权重
- 输入格式：`F1:pl S1 S2 ...`，S 为曲面编号
- **限制**：仅可用于栅元边界曲面且已在栅元卡中列出的曲面

#### F2 — 曲面通量
- 曲面上平均通量（需曲面面积）
- 输入格式：`F2:pl S1 S2 ...`
- **限制**：仅可用于栅元边界曲面且已在栅元卡中列出的曲面

#### F4 — 栅元通量
- 栅元内径迹长度估计的通量
- 最常用的记数类型之一
- 输入格式：`F4:pl C1 C2 ...`，C 为栅元编号

#### F5 — 探测器
- **点探测器**：`F5:pl X Y Z ±R0`
  - X Y Z = 探测器位置
  - R0 > 0 = 排斥球半径（cm）；R0 < 0 = 排斥球半径（mfp）
  - **注意**：R0 < 0 在真空中非法（FATAL error）
- **环探测器**：`Fna:pl a0 r ±R0`
  - `a` = X/Y/Z（环轴方向，作为字母追加到记数编号后，如 `F5X:N`）
  - a0 = 轴上距离；r = 环半径
- **通量成像**（记数编号以 5 结尾）：
  - `FIPn` — 针孔成像（pinhole）
  - `FIRn` — 平面矩形网格成像（radiograph）
  - `FICn` — 圆柱面网格成像
- 探测器总数 ≤ 20
- 探测器结果误差：< 5% 通常可靠
- R0 经验法则：约为平均自由程的 1/8 ~ 1/2，真空中为 0

#### F6 — 能量沉积
- 栅元中能量沉积（不包含裂变能量）
- `*F6` 将单位从 MeV/g 变为 jerks/g（1 jerk = 1 GJ = 10⁹ J）
- 不允许电子（:E）

#### F7 — 裂变能量沉积
- 栅元中裂变能量沉积
- 仅中子（:N）

#### F8 — 脉冲高度
- 探测器中的脉冲能量分布
- `*F8` → 能量沉积记数（非脉冲高度）
- `+F8` → 电荷沉积记数（单位：电子电荷）
- **注意**：F8 与中子兼容性差（中子输运的非类比特性），建议仅用于光子/电子问题
- 能量分箱建议包含零箱和 epsilon 箱：`E8 0 1E-5 1E-3 1E-1 ...`

## 四、记数格式详解

### 4.1 曲面/栅元记数（F1, F2, F4, F6, F7）

**简单格式**：
```
Fn:pl S1 ... Sk
```

**通用格式**：
```
Fn:pl S1 (S2 ... S3) (S4 ... S5) S6 S7 ...
```

- `n` = 记数编号
- `pl` = N（中子）/ P（光子）/ N,P（中子光子）/ E（电子）
- `Si` = 曲面或栅元的编号，或 `T`
- `T` = 当前卡上其他所有项的并集
- **括号内** = 并集（union），对 F1 为求和，对 F2/F4/F6/F7 为平均

**示例**：
```
F2:N 1 3 6 T
```
→ 4 个中子通量记数：曲面 1、3、6 各自 + 三者平均

```
F1:P (1 2) (3 4 5) 6
```
→ 3 个光子电流记数：1+2 之和、3+4+5 之和、6 单独

### 4.2 探测器格式（F5）

```
F5:pl X Y Z ±R0
```
点探测器：位置 + 排斥球半径（正 = cm，负 = mfp）

```
F5a:pl a0 r ±R0
```
环探测器：a = X/Y/Z 轴方向；a0 = 轴上距离；r = 环半径

### 4.3 脉冲高度记数格式（F8）

```
F8:pl S1 ... Sk
```

- 输入同 F4（栅元列表）
- 栅元并集 = 求和（非平均）
- 允许：栅元分箱、能量分箱、用户分箱
- 不允许：标记、分段、乘子、时间分箱、余弦分箱
- 若同时存在光子和电子，两者都会被记入，即使 F8 卡上只写了 :P 或 :E

## 五、记数卡修饰（* 和 +）

| 前缀 | 效果 |
|------|------|
| `*Fn` | F1/F2/F4/F5：记数 MeV（能量 × 权重）而非粒子数 |
| `*Fn` | F6/F7：单位从 MeV/g 改为 jerks/g |
| `*F8` | 脉冲高度 → 能量沉积记数 |
| `+F8` | 脉冲高度 → 电荷沉积记数（单位：电子电荷） |

## 六、记数编号规则

- 记数编号 = 1, 2, 4, 5, 6, 7, 8 或以 10 为倍数的增量（如 11, 21, ..., 101...）
- 编号不超过 3 位数字
- 粒子标识：`:N`（中子）、`:P`（光子）、`:E`（电子）、`:N,P`（中子+光子，仅 F6）、`:P,E`（光子+电子，仅 F8）
- 同一 INP 文件中不允许同时出现 `F1:N` 和 `F1:P`
- 记数总数 ≤ 100

**合法示例**：
```
F4:N         F14:N        F104:N       F234:N
F5:P         F15:P        *F305:P
```

## 七、输出质量判断

| 相对误差 | 可靠性 |
|---------|--------|
| > 50% | 无用 |
| 20% ~ 50% | 可置信到数倍以内 |
| 10% ~ 20% | 可疑 |
| < 10% | 通常可靠（探测器除外） |
| < 5% | 探测器结果通常可靠 |
